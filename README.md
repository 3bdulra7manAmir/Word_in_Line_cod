Filtering, comparison, and asset-list cleanup tools for Call of Duty content pipelines.

## Project Snapshot
The scripts in this workspace focus on sorting, diffing, and refining CSV or text-based asset lists.

- Main entrypoint: `assets_finder.py`
- Typical start command: `python assets_finder.py`
- `assets_finder.py`
- `berlin.csv`
- `difference_finder.py`
- `FilterBy.py`
- `FilterBy2.py`
- `Incoming.txt`
